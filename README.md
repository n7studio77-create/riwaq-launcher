# رِواق — مكتبة الألعاب العربية

لانشر ويندوز عربي للألعاب والمودات والتعريبات، مع تسجيل دخول إجباري ومكتبة شخصية وإدارة محتوى للمالك. الحسابات والبيانات تحفظ في Supabase، والتنزيلات تحفظ مباشرة على جهاز اللاعب.

## بناء تطبيق ويندوز

1. ثبّت Node.js 26 LTS أو أحدث.
2. من مجلد المشروع نفّذ `npm install` ثم `npm start` لتشغيل التطبيق.
3. أنشئ ملف التثبيت باستخدام `npm run dist:win`. الناتج يظهر في مجلد `release`.
4. تُحفظ التنزيلات في `Documents\Riwaq Library`، داخل مجلد مستقل لكل عنصر. تظهر الملفات المكتملة في «مكتبتي» على هذا الجهاز بعد تسجيل الدخول. يعرض التطبيق تقدم التنزيل مع إيقافه مؤقتاً أو استئنافه، ولا يفك ملفات ZIP أو يشغّل الألعاب تلقائياً.
5. بعد إنشاء المستودع العام ونشر إصدار عليه، يفحص التطبيق التحديثات تلقائياً عند التشغيل، وينزّلها في الخلفية، ثم يثبتها عند إعادة التشغيل أو إغلاق التطبيق. تُنشر الإصدارات عبر GitHub Releases للمستودع `n7studio77-create/riwaq-launcher`. من يستخدم إصداراً أقدم من 1.0.2 يحتاج تثبيت 1.0.2 مرة واحدة لتفعيل التحديث التلقائي وإضافة المحتوى بروابط مباشرة.

## نشر تحديث جديد

1. أنشئ مستودع GitHub عاماً باسم `riwaq-launcher` تحت حساب `n7studio77-create` وارفع ملفات المشروع إليه. المستودع العام يجعل ملفات المصدر عامة؛ راجع الملفات وتأكد من عدم وجود أسرار أو بيانات خاصة قبل الرفع.
2. انشر الإصدار الأول المحدّث بوسم يطابق `package.json`، وهو `v1.0.3`. ينشئ GitHub Actions إصدار Windows ويرفع ملفات التحديث تلقائياً. مستخدمو النسخة القديمة يثبتون `Riwaq-Setup-1.0.3.exe` مرة واحدة.
3. لكل تحديث لاحق، زد `version` في `package.json`، ثم ادفع التغيير ووسمًا مطابقًا مثل `v1.0.4`. سيفحص التطبيق الإصدار الجديد تلقائياً لدى المستخدمين.

## إعداد Supabase

1. أنشئ مشروعاً في [Supabase](https://supabase.com/).
2. استخدم Supabase للمصادقة والكتالوج والمكتبة فقط. ملفات الألعاب وصور الأغلفة الجديدة تستضاف عند مزوّد خارجي؛ أضف روابط HTTPS مباشرة لها، ولا ترفع ملفات إلى Supabase.
3. افتح **SQL Editor** وشغّل `supabase/schema.sql` لإعداد الجداول وسياسات الوصول. لا يلزم تغيير حدود Storage لإضافة روابط تنزيل مباشرة. مخازن Storage وسياساتها باقية للتوافق مع عناصر ZIP قديمة فقط.
4. من **Project Settings → API** انسخ رابط المشروع ومفتاح `anon`/`publishable` العام إلى `config.js` إذا استبدلت المشروع:

   ```js
   window.GAME_HUB_CONFIG = {
     supabaseUrl: "https://YOUR-PROJECT.supabase.co",
     supabaseAnonKey: "YOUR-PUBLIC-ANON-KEY"
   };
   ```

   استخدم المفتاح العام فقط. لا تضع `service_role` أو كلمات مرور في ملفات الموقع.
5. فعّل تأكيد البريد في **Authentication → Providers → Email**، واضبط رابط موقعك ضمن **Authentication → URL Configuration**.
6. لتشغيل نسخة الويب، ارفع الملفات إلى استضافة HTTPS مثل Cloudflare Pages أو Netlify أو GitHub Pages. يتطلب التطبيق المكتبي Node.js للبناء فقط.

## الحساب والمالك

- الزوار يقدرون يتصفحون المكتبة؛ إضافة المحتوى إلى «مكتبتي» وفتح روابطه يتطلب تسجيل الدخول. روابط المصدر محفوظة في جدول منفصل محمي بسياسات RLS، ولا تظهر للزوار أو للحسابات التي لم تضف العنصر إلى مكتبتها.
- أنشئ حساباً من زر الحساب في الموقع. سيُمنح البريد `77kmf13@gmail.com` صلاحية المالك تلقائياً بعد تأكيد البريد، سواء كان الحساب موجوداً عند تشغيل SQL أو أُنشئ لاحقاً.
- المالك يشوف زر **إدارة المحتوى** لإضافة الألعاب والمودات والتعريبات وحذف العناصر. يتطلب النموذج رابط تنزيل HTTPS مباشر ورابط صورة غلاف، ويخزن Supabase بيانات الكتالوج والروابط المحمية فقط؛ حجم التنزيل تحدده استضافة الرابط الخارجية. تظل عناصر ZIP القديمة المخزنة في Supabase قابلة للتنزيل.
- عند إدخال رابط تنزيل مباشر، يستخرج التطبيق اسماً من اسم الملف ويبحث عنه في Steam لاقتراح العنوان والغلاف والوصف والمنصة والتصنيف. يمكن إدخال رابط صفحة Steam اختياريًا لبحث أدق. راجع الاقتراحات وعدّلها قبل إضافة العنصر؛ أضف غلاف HTTPS يدويًا إذا لم يتوفر اقتراح.
- لا تضع كلمة المرور في `config.js` أو الكود. إذا كانت كلمة مرور الحساب قد تمت مشاركتها، غيّرها من إعدادات الحساب قبل الإطلاق.
- بعد ربط Supabase تبدأ المكتبة فارغة؛ أضف المحتوى وروابطه من لوحة المالك.

## المحتوى والتنزيل

إضافة العنصر إلى «مكتبتي» تحفظه في حساب المستخدم؛ بعدها ينزّل تطبيق ويندوز الملف من رابط HTTPS مباشرة إلى مجلد `Documents\Riwaq Library` على الجهاز. يُسجل التطبيق الملفات المكتملة محليًا ويتيح إظهار موقعها من المكتبة. التنزيل يمر مباشرة إلى القرص ولا يُحمّل كاملاً في ذاكرة التطبيق. يجب أن يكون الرابط مباشراً لملف قابل للتنزيل، وليس صفحة ويب. أضف ملفات تملك حق توزيعها أو روابط المصادر الرسمية المناسبة؛ مزوّد الرابط هو المسؤول عن التخزين والنقل وحدودهما.
